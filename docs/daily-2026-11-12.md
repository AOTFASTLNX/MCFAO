# daily/2026-11-12 — iOS launcher, control layouts, memory budget, frame-rate work

Self-contained snapshot of everything that shipped on 2026-11-12, based on
`fix/ipados-mouse-trackpad-look` (the branch that carries the iPadOS pointer bridge).

## What runs today

Minecraft Java Edition 26.1.2 boots on a stock iPhone/iPad with no JIT: the client is AOT
compiled by GraalVM Native Image 25 and renders through the Metal backend, `libglfw` and
OpenAL Soft. The launcher hands the selected settings to the harness and the game reaches the
main menu and a world.

## Contents

- `ios/C0Harness/FAOTLauncherViewController.*` — pre-game launcher (player name, memory budget,
  layout picker, `Edit controls`, `Import Pojav layout`, `Launch Minecraft`, `Diagnostics`).
  Scrolls in landscape; a second launch turns the button into `Restart App` because a Graal
  isolate exists only once per process.
- `ios/C0Harness/FAOTControlLayout.*` — Pojav `mControlDataList` parsing (dynamic
  `${margin}`/`${width}`/`${bottom}` expressions, `KEY_*` codes, `scaledAt` canvas) and
  `Documents/controlmap/<name>.json` persistence.
- `ios/C0Harness/FAOTControlsOverlay.*`, `FAOTControlEditorViewController.m` — drag to move,
  pinch to resize, tap to rebind.
- `ios/glfw-lite/uikit_surface.m` — installs the on-screen buttons from the selected layout and
  keeps the fork's pointer/trackpad bridge.
- `ios/C0Harness/main.m` — memory picker becomes `-Xmx`, reserved address space is derived as
  heap + 1 GiB, Metal budget scales with RAM inside the backend's 256–1024 range, faster
  `options.txt` defaults.
- `ios/metal-bridge/metal_bridge.m` — VSync through `CAMetalLayer.displaySyncEnabled`, three
  drawables, `framebufferOnly`.
- `ios/glfw-lite/glfw_lite.c` — `glfwSetCursor` no longer formats a message into `stderr` every
  frame.
- `tools/probe_client_graph.py` — AOT at `-O3` (`MCFAO_OPT_LEVEL` overrides).
- `ci/` — the exact pipeline used for today's builds: `build_mac.sh`, `build_sim.sh`,
  `patch_src.py`, `VerifyClasses.java`, `classdump.py`, `fetch_minecraft.py` and the CircleCI
  configuration (`ci/circleci/config.yml`, kept out of `.circleci/` so this repo does not start
  its own pipelines).

## Build and install

The build runs on CircleCI `m4pro.medium` (macOS 26, 28 GiB) because the GraalVM analysis needs
more than the 7 GiB GitHub runners provide:

```
MCFAO_TOKEN=... HEAP_GIB=8 JOBS=6 AOT_PAR=4 SLIM_ASSETS=1 bash ci/build_mac.sh
```

Signing happens in a separate private repository, then the IPA is installed with
`pymobiledevice3 apps install`.
