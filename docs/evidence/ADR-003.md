# ADR-003：真实客户端入口与原生调用诊断

日期：2026-11-08。**C0 BLOCKED，C1/C2 NOT RUN。** A0/A1/B0/B1已经各自验证；本记录不构成游戏启动或画面验收。

## 已读取的真实输入

用户本地合法客户端26.1.2，SHA256 b1b3158572666445eff01e82fad8c7de2e4953db6d354f311730d77a8359d0b0。只读使用A0已指纹化的共享依赖，未执行用户Mod、Gradle脚本或游戏Main，也未读取账户、令牌、玩家存档或游戏原始进程参数。

inventory_client_native_calls.py静态扫描10682个class文件，得到319个唯一LWJGL方法引用候选：OpenGL124、GLFW85、OpenAL35、system36、util26、STB6，以及PointerBuffer5、BufferUtils1、Version1。完整符号清单为 artifacts/evidence/client-native-call-inventory.json。这不是实际执行覆盖率；反射、JNI回调与动态解析可能增加依赖，尚无逐调用iOS测试。

因此仍需真实图形/窗口/音频适配。当前未选定可运行的Metal后端，没有将macOS原生库重标为iOS，也没有用3D测试图形代替真实Minecraft菜单。API版本、着色器语义、触摸输入、音频和逐调用测试还需随真实客户端引导完善。

## 真实入口可达性实验

probe_client_graph.py以net.minecraft.client.main.Main为分析根。Native Image25.0.2目标iOS arm64，使用本项目实际编译的iOS java/nio/net等静态库及固定版本数值CAP。只执行ExitAfterAnalysis；关闭工具链外部探测属于分析诊断配置，不能据此生成可分发游戏库。没有完成全客户端Fabric静态转换、资源闭包或JNI绑定。

每轮先用第一方程序证明工作区外文件读/写和本地socket连接受拒绝，再运行分析器。默认拒绝沙盒仅允许固定工具链、客户端/依赖JAR、iOS运行库，以及明确的clang路径；环境和写入目录独立。CPU/时间/输出/单文件/描述符受限，这仍不是完整D0认证。

| 记录 | 实际结果 |
|---|---|
| client-graph-01/02 | 未定位可用clang；未进入完整分析 |
| client-graph-03 | 缺少静态运行库路径；后续显式使用实际iOS库 |
| client-graph-04/05 | 分析过程中退出152；05记录约602.8秒子进程CPU，符合600秒预算耗尽，不作为AOT不兼容证据 |
| client-graph-06 | 外层受限执行返回EPERM，未运行分析；保留失败记录 |
| client-graph-07 | 沙盒控制PASS；堆上限6 GiB、4线程、墙钟600秒/CPU1800秒。分析器明确报告java.lang.OutOfMemoryError: Java heap space，退出3，子进程CPU约566.1秒；未生成客户端原生对象 |

原始日志、命令、沙盒策略与哈希在 artifacts/c0/client-graph-07/。这是当前构建预算内未能完成分析的证据，不能断言增加内存后一定通过，也不能断言客户端不可AOT。后续需在有界资源条件下完成闭包/初始化/反射诊断，再验证真实无图形引导和JNI；C0通过之前不提升C1/C2。

## 复现

```bash
python3 -B tools/inventory_client_native_calls.py --output artifacts/evidence/client-native-call-inventory-new.json
python3 -B tools/probe_client_graph.py --output artifacts/c0/client-graph-new
```

输出目录必须不存在，且先有已确认的B1真机证据。当前默认复现使用6 GiB堆、墙钟600秒/CPU1800秒；这可能重现内存失败。失败记录必须保留，不以预算耗尽代替语义不兼容结论。
