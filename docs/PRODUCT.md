# FabricAOT — 终版产品需求

> 2026-11-15 集成决策：本轮交付范围是 Apple Silicon macOS 的 desktop/ Tauri 2 构建器与 GL41 测试 IPA。GUI 应提供 GL41 和可选原生 Metal，执行真实 AOT、实时日志、取消、失败重试和 IPA 清单。仅 prepare-only 不算完成。所有真机游玩与 Fabric 功能分别验收。


## 产品定位

Mac 上的 Fabric 26.1.2 静态构建器 + iPhone 本地原生客户端。用户导入 `.mrpack` / Prism 实例，构建器解析依赖、诊断兼容性、执行构建期类转换、编译 AOT、对接 iOS 渲染与输入，最后生成用户自行签名并安装的 IPA。终端 iOS 无需 Java JIT、越狱、PC 串流。

## Mac 界面

1. 首页：新建/最近构建，诊断工具链状态（Xcode/JDK 25/GraalVM iOS 可用性/签名）。
2. 导入：文件选择、拖放 `.mrpack`、Prism 实例目录；不解压无关路径，不信任压缩包内容。
3. 依赖：解析 manifest、从官方/可信来源下载允许下载的文件，校验哈希；清楚展示缺失/被限制的专有文件与手动导入动作。
4. Mod 诊断：名称、ID、版本、入口点、Mixin、语言适配器、JNI/动态加载风险、Fabric 依赖冲突、版权许可；以 VERIFIED / UNSUPPORTED / UNKNOWN 区分，禁止无依据的兼容承诺。
5. 配置：输出文件名、签名配置、图形与内存档位、保留调试符号选项；中文 UI 优先，提供英文。
6. 构建：实时每步日志、取消、错误解释、可重试、日志导出、可重现构建清单。
7. 安装：导出 .ipa + 安装说明，检查 Personal Team/free provisioning 是否可行。禁止嵌入用户的私密签名证书。

## iOS 客户端

- 真机从主菜单进入 Minecraft 26.1.2，单人世界、触摸/键鼠/手柄、音频、存档/备份/导入导出、服务器直连（**v1 后独立验收，不宣称 v1 支持**），游戏设置（视距、帧率限制、画质、UI 比例）。
- 应用切后台自动暂停与保存，避免系统回收时损坏世界；权限与沙盒最小化，应用外不联网也能玩单人世界。
- 提供 GPU/CPU 帧时间、1% low、峰值内存、区块加载性能与崩溃报告。不得制造/虚构跑分。

## 明确非目标

- Forge / NeoForge / Quilt；Android；云游戏；未经验证的任意 Mod 热加载；在 iPhone 上实时编译 Java；向第三人分发 Minecraft 本体或用户授权资产。

## 质量

- 构建器对不安全路径/异常 ZIP/哈希不符/恶意下载地址给出安全失败。
- 与正版 Minecraft 登录、离线单人启动的许可条件保持一致，不能用伪造 Microsoft 授权替代合法验证。
- 大型整合包不保证支持；显示具体阻断问题，不得“兼容率 100%”伪宣传。

## 版本范围声明（审查修订）

`v1` **最低可玩交付**：26.1.2、单人世界、真实 Fabric Mod 行为、触摸/声音/存档、至少一份经过完整验证的兼容整合包、在未越狱 iPhone 无 Java JIT 运行。联机、任意 Mod、大型整合包均不是未经验证的保证；有明确的后续独立验收流程。若用户期待联机属于终版必需，须升级验收范围而不能默默忽略。

**实际安全/法律约束**：在 Mac 上导入来源不明的 Mod 仍可能触发执行不可信代码；不许直接执行未隔离的第三方 Gradle/Mod 初始化脚本。最终游戏文件用户本地合法获取并构建，不公开再分发含 Minecraft 代码的 IPA。个人免费签名可能 7 天过期，更新和存档保留必须实测。
