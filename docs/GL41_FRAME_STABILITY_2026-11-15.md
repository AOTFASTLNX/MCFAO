# GL41 帧率稳定性改造（2026-11-15）

> 目标从「峰值帧数」改成「**波动越小越好**」。v14 的实测区间是 46–86 FPS，
> 用户反馈"一卡一卡的"，这一版专门处理节奏不稳。

## 1. 为什么 v14 会抖

| 事实 | 数据 |
|---|---|
| 一帧的 GPU 成本 | `finish` ≈ 9 ms（`glFinish` 到 OSMesa 回读完成） |
| 一帧的 CPU 成本 | `outsideSwapP95` ≈ 7–8 ms |
| 游戏请求的帧率 | 选项加载后 `maxFps=120` → 目标间隔 **8.3 ms** |
| 实际帧率 | 46–86 FPS（中位 58–71） |

结论：**120 Hz 的目标在这台设备上永远达不到**。限速器的固定截止时间每一帧都过期，
`FramePacing` 里的"迟到就重锚"分支每帧都触发，于是限速器事实上不工作——帧率完全由当帧
渲染成本决定，场景一复杂就掉到 46，简单时冲到 86。

也就是说：v14 的"抖动"不是限速器太严，而是**限速器根本没在限**。

## 2. 这一版改了什么

`compiler/gl41/tools/fabricaot/gl41/FramePacing.java` 重写为自适应限速：

1. **可持续目标阶梯**：`120 → 90 → 72 → 60 → 48 → 30`，永远不超过游戏请求的帧率。
2. **启动就从 60 起跑**，而不是先按 120 空转几秒。
3. **滞回**：连续 2 个 2 秒窗口都偏慢才降一档；连续 2 个窗口都明显有余量（平滑帧间隔
   低于目标的 85%，且 p95 也低于目标间隔）才升一档。避免在两档之间来回跳。
4. **绝对截止时间**保持不变；越过一整个间隔时重锚，不产生补帧突发。
5. **等待策略**：大于 1.2 ms 的等待用 `parkNanos`（iOS 上会多睡几毫秒，所以留 0.8 ms 余量），
   最后一毫秒自旋，把节奏误差压到微秒级。
6. **每 2 秒输出一行节奏日志**，带平滑帧间隔、p95、最大值和升降档计数。

对照开关：环境变量 `FAOT_PACING=fixed` 可恢复 v14 的旧行为，用于 A/B 对比。

## 3. 预期日志

```
[GL41] pacing target=60 requested=120 mode=adaptive
[GL41] pacing fps=60 requested=120 ema=16.6ms p95=17.1ms max=23.4ms steps=0down/0up
[GL41] pacing step up 60 -> 72 (ema 11.9ms, p95 12.4ms)
[GL41] pacing fps=72 requested=120 ema=13.9ms p95=14.6ms max=19.8ms steps=0down/0up
[GL41] pacing step down 72 -> 60 (ema 17.4ms > 16.0ms)
```

配合这一轮同时加的帧成本拆分（见 `osmesa_gl.c`）：

```
[GL41] perf fps=60.1 flush=1.20ms gpu=8.10ms finish=9.30ms present=1.15ms finishP95=11ms outsideSwapP95=7ms
```

- `flush` 大 → zink 的 CPU 提交开销大（要减少 draw call / 状态切换）；
- `gpu` 大 → 卡在 Metal 或 OSMesa 回读（要考虑呈现路径改造）。

## 4. 验收标准（真机）

同一存档、进世界后稳定 60 秒，对比 v14：

| 指标 | v14 | 本版目标 |
|---|---|---|
| 跨窗口 FPS 标准差 | 约 10 | **< 3** |
| 帧间隔 p95 | 21 ms | **≤ 1.25 × 目标间隔**（60 档 → ≤ 21 ms，72 档 → ≤ 17 ms） |
| 最长帧间隔 | 40 ms+ | **< 2 个间隔** |
| 1% low（按窗口） | 46 FPS | **≥ 0.9 × 目标** |

如果阶梯停在 60 但波动明显变小，说明改造生效——这是用峰值换稳定，符合本次目标。
若更想要高帧，可把阶梯改成 `{120, 90, 72}` 或调整 `EARLY_RATIO`。

## 5. 已知取舍

- 平滑帧间隔仍会受区块加载影响（进世界第一分钟），限速器只能保证"节奏均匀"，
  不能消除单帧长耗时。真正消除需要把区块网格上传移出主线程。
- 若某个场景持续在 55–60 之间摇摆，阶梯可能停在 48；这是刻意选的：宁可稳 48，不要抖 60。
