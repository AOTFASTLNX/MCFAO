## Build blockers resolved

The output directory used by the JVM sandbox probe was a symlinked path.
Canonicalizing the existing physical output directory before constructing
the probe policy fixed the cwd mismatch; this full AOT build passed.

The local `aar` executable was a broken symlink to a removed registry tool.
`register_tree()` now retains the exact registration request in
`registration-pending.json` when launching the executable raises
`FileNotFoundError`. Other registry errors remain fatal. Registration is
pending; security, AOT, linking and package validation are still enforced.
